Installing

  1. Open the downloaded AGAPAY-Setup.exe.
  2. If Windows shows "Windows protected your PC", click More info, then Run anyway. This appears because the installer is new to Windows.
  3. Create the Administrator account (the Municipal Agriculturist), then click Install.
  4. AGAPAY opens in the browser. Do the first setup in chapter 9 of the User Guide before the staff start encoding.

AGAPAY runs on the office laptop itself and needs no internet for daily use. The installer holds no farmer records; the records stay on the laptop, with a backup every day.

Already installed?

Updating
No need to download again. The Administrator sees Update available in AGAPAY's side panel when a new version is out.
Reinstalling
Running a newer installer keeps the records; it makes a backup first.
